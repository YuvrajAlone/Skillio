# Skillio 🚀

**Practice. Prepare. Perform.**

Skillio is a full-stack interview platform that helps developers get ready for technical interviews through practicing problems and realistic interview sessions.

Users can practice coding problems independently to improve their problem-solving skills. When they're ready, they can join a technical interview session where they are given problems to solve in an interview-like environment, with video calling and real-time chat.

## ✨ Features

### 🧩 Coding Practice

- Practice problems to improve problem-solving skills.
- Write solutions using the Monaco code editor.
- Support for JavaScript, Python, and Java.
- Execute code and view the output directly in the editor.

### 🎯 Technical Interview Sessions

- Create and join interview sessions.
- Solve a given problem in a realistic technical interview environment.
- Practice approaching and solving problems under interview conditions.

### 🎥 Video Calling

- Real-time audio and video communication during interview sessions.
- Connect with interview participants in a live interview environment.

### 💬 Real-Time Chat

- Communicate with participants during interview sessions.
- Real-time messaging and message threads.

### 🔐 Authentication

- User authentication using Clerk.
- Protected routes and authenticated access.

### ⚡ Code Execution

- Execute code through the OneCompiler API.
- Support for multiple programming languages.
- View execution output within the coding interface.
